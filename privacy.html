Privacy policy · Updated 18 November 2026

Your clips stay on your computer

This covers the CLIPPR Chrome extension and this website: what stays on your computer, what is sent, and to whom.

In short

  • Nothing you record, edit or export is uploaded to CLIPPR.
  • Our license server knows your email, your plan and which install is signed in.
  • Usage events go to PostHog and can be turned off in Settings → Privacy.

Nothing you record, edit or export is sent to CLIPPR. The only things CLIPPR’s own server sees are your subscription and license key, described below.

What stays on your computer

  • The rolling buffer of the stream you are watching, held in memory and dropped when you close the tab.
  • Your clips, projects and exports, stored in the extension’s own browser storage and saved to your Downloads/Clippr folder.
  • Your settings, saved caption styles and any API keys you add, stored in Chrome’s extension storage.
  • Your license key and a random id for this install, stored in Chrome’s extension storage.

Subscription and license

CLIPPR is a subscription with a 7-day free trial. Checkout and billing are handled by Stripe, which receives your email address and payment details under its own privacy policy; CLIPPR never sees your card. CLIPPR’s license server (on Cloudflare) keeps:

  • your email address, Stripe customer and subscription ids, subscription status and license key;
  • the random install id the license is signed in on, and a log of when and how it moved between installs (used to stop a key being shared);
  • a fingerprint Stripe computes for your card (not the card number), so each card gets one free trial;
  • while you sign in by email, a one-way hash of the 6-digit code and how many times it was tried, kept until the code expires.

Sign-in codes are emailed through Resend, which receives your email address to deliver them. The extension checks in with the license server about once an hour, and before each export, to confirm your plan and that the license is still signed in on this computer.

Usage statistics

The extension sends usage events to PostHog (US) so we can see which features and streams CLIPPR gets used on: for example that a clip was saved, from which Twitch or Kick channel, its length, quality and size; that an export finished, with its format and resolution; which caption engine was used; your plan state; and plan events such as a trial starting. Each event carries the random install id and the extension version. That install id is the same one the license server records, so events can be linked to your subscription; they carry no name or email themselves. PostHog also receives your IP address with each event and derives an approximate location from it. Events never include your video, audio, captions, file names, API keys or license key; error messages are trimmed of file names and paths before they’re sent. Turn events off any time in Settings → Privacy.

What is sent, and to whom

  • CLIPPR’s license server, Stripe, Resend and PostHog: as described above.
  • Twitch and Kick: the same video requests your player already makes, so CLIPPR can read the stream. For Twitch, your Twitch sign-in cookie is used for those requests only.
  • Hugging Face: the speech model is downloaded once from huggingface.co the first time you make captions on your computer.
  • jsDelivr: a font file is downloaded the first time you choose that font.
  • Groq or OpenAI, only if you add your own key: the clip’s audio is sent to that provider for captions, under its own terms. Your key is sent only to that provider.

This website

This site is static, on GitHub Pages. It sets no cookies and runs no analytics. GitHub receives the usual request details, such as your IP address, when a page loads. Fonts are served from this site.
